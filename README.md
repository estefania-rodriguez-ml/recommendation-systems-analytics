# Recommendation Systems & Customer Analytics

## Overview

This project explores recommendation systems and customer purchasing behaviour using machine learning techniques and large-scale datasets.

The project combines:

- Collaborative Filtering
- Content-Based Filtering
- Market Basket Analysis
- Interactive Dashboarding

## Objectives

- Generate personalised recommendations
- Analyse customer behaviour patterns
- Identify relationships between products
- Support business-oriented decision making through data analysis

## Datasets

### Goodbooks-10k
Book ratings and metadata dataset used for recommendation systems.

### Grocery Transactions Dataset
Synthetic retail transaction dataset used for Market Basket Analysis.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit

## Models Implemented

### Collaborative Filtering
- User-user recommendations
- Item-item recommendations
- KNN recommendation model
- Cosine similarity

### Content-Based Filtering
- TF-IDF vectorisation
- Book similarity analysis using metadata and tags

### Market Basket Analysis
- Apriori algorithm
- FP-Growth algorithm
- Association rule mining

## Key Insights

- Item-item collaborative filtering produced more stable recommendations in sparse datasets.
- Content-based filtering improved thematic recommendation quality using book metadata.
- Market Basket Analysis identified product associations useful for retail optimisation and customer targeting.
